## Dependencies

Clockwork is an addon and does not run alone. It attaches to:

- **Valkyrien Skies 2** — https://github.com/ValkyrienSkies/Valkyrien-Skies-2 (Apache-2.0)
- **Create** — https://github.com/Creators-of-Create/Create (MIT)

Neither is vendored here; both are resolved as ordinary build dependencies.
