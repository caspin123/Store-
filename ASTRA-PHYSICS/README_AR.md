# ASTRA Physics 0.1.0-alpha

مركبات متحركة لماينكرافت 1.21.11 / Fabric / Java 21، بجافا خالصة وبدون أي مكتبات أصلية.
مبني ومجرَّب على أندرويد ARM64 (FCL) إضافةً للحاسوب.

حدّد بناءك بالعصا، جمّعه، ويصير جسم واحد متحرك تقدر تبحر وتطير فيه وتمشي على سطحه.

## المكوّنات

| البلوك | الوظيفة | الحركة |
|---|---|---|
| **الدفة** | مركز القيادة. اضغط يمين لتمسك المقود. | خمس وضعيات للمقود، من أقصى اليسار لأقصى اليمين، مع سنّ مميّز يوضّح الزاوية |
| **المحرك** | مصدر الطاقة. يمين لتغيير القدرة OFF / 25 / 50 / 75 / 100%. تسلل + يمين لتبديل بحري/جوي. | دولاب التوازن يدور وثلاثة مكابس تعمل بسرعة تتبع القدرة |
| **المروحة** | تحوّل قدرة المحرك لدفع. تدفع بعكس الوجه اللي تشير له. | أربع شفرات تدور، وتتوقف بدون قدرة وسرعة معاً |
| **الشراع** | دفع بالرياح بدون محرك. يتوصّل — حطّ مجموعة منه لشراع أكبر. | القماش ينتفخ بموجة تعبر الشراع |
| **الجناح** | رفع في النمط الجوي. ركّبه أزواجاً متقابلة تشير للخارج. يتوصّل — حطّ عدة بلوكات بصف لجناح أطول. | الجنيح ينحرف مع توجيه القائد |
| **الدافع** | رفع عمودي، أقوى في النمط الجوي. | لهب العادم يكبر وينبض، وفوهة باردة عند التوقف |
| **عجلة رد الفعل** | تدوّر الهيكل بدون حاجة لسرعة — استدر وأنت واقف. تحتاج طاقة محرك. | دوّار الجيروسكوب يدور وهي تشتغل |
| **المنطاد** | طفو بالهواء. ما يحتاج محرك، والرفع يقل مع الارتفاع. | الغلاف يتنفّس |
| **الجناح المنحني** | يرفع بقوة عند السرعة الواطية، مقابل مقاومة أكثر. اخلطه مع العادي. يتوصّل. | الجنيح ينحرف مع التوجيه |
| **المثبّت** | زعنفة عمودية. تخمد الدوران فتثبت السفينة على اتجاهها. تحتاج جريان هواء. | لسان الضبط ينحرف |
| **مقياس الارتفاع** | يمين لتثبيت الارتفاع الحالي. يحتاج دوافع أو مناطيد. | ضوء التفعيل |
| **الجيروسكوب** | يمين لتثبيت الاتجاه الحالي. | الدوّار يدور |
| **منظّم السرعة** | يحدّ السرعة القصوى بدون تقليل قدرة المحرك. | الذراع تبيّن الإعداد |
| **مُجمِّع الفيزياء** | اضغط عليه يمين بالعالم فيتجمّع كل شي متصل بيه — بدون عصا وبدون زوايا. ويبقى جزء من السفينة. | النواة ترتفع وتضوّي ما دامت المركبة حية |
| **عجلة الهبوط** | تنزل لما تقرب المركبة من الأرض وتنطوي لما ترتفع. تشتغل لحالها، ما عليك تتذكّرها وقت النزول. | الساق تمتد على أربع مراحل |

الحركة مربوطة بحالة السفينة الحقيقية مو بدورة ثابتة: سفينة راسية مراوحها ساكنة، والدافع ما يشتعل
إلا مع سرعة للأمام.

## طريقة الاستعمال

1. اصنع **عصا ASTRA الفيزيائية**.
2. اضغط يمين على زاوية من بناءك، ثم على الزاوية المقابلة.
3. اضغط يمين مرة ثالثة للتجميع. البلوكات تخرج من العالم وتصير مركبة.
4. اضغط يمين على **الدفة** لتمسك المقود: `W`/`S` للسرعة، `A`/`D` لتدوير السفينة، قفز وتسلل
   للصعود والنزول، `G` للترك (الضغط يمين على المقود مرة أخرى يشتغل بعد). تبقى الكاميرا تحت
   سيطرتك بالكامل أثناء القيادة.
5. اضغط `V` لتبديل وظيفة العصا: **تجميع** أو **تفكيك** (اضغط على مركبة فترجع بلوكات) أو
   **مسك** (تحمل المركبة على امتداد نظرك) أو **تجميع + مسك** (الاثنين بضربة وحدة، فالهيكل الجديد
   ما يطيح من السقالة). و`/astra disassemble` باقي للمشرفين.

أو خلّ الزوايا كلها: حطّ **مُجمِّع الفيزياء** على البناء واضغط عليه يمين. يتتبّع البلوكات من نفسه
للخارج، فياخذ الشكل اللي بنيته فعلاً مو صندوق — الصواري داخلة، والتلة اللي تحته لا. وإذا البناء
بعده لاصق بأرض ما يصح ياخذها، يرفض ويقلك وين، بدل ما يخمّن.

لازم يكون التحديد مجموعة بلوكات متصلة، ولازم يكون مسموح لك بالبناء بالمكان — التجميع يحذف بلوكات
من العالم، فهو يحترم حماية السبان ومودات الحماية.

## الأوامر

كلها تحتاج صلاحية 2. تقدر تختصر معرّف المركبة لأي بداية فريدة، وكل أمر يستهدف أقرب مركبة إذا ما
كتبت المعرّف.

| الأمر | الوظيفة |
|---|---|
| `/astra list` | المركبات في هذا البعد |
| `/astra info [id]` | الموقع، السرعة، الكتلة، نسبة الغمر، المحرك وعدد المكوّنات |
| `/astra disassemble [id]` | إرجاع بلوكات المركبة للعالم |
| `/astra remove <id>` | حذف المركبة **بدون** إرجاع بلوكاتها |
| `/astra save` | حفظ فوري لكل المركبات |
| `/astra reload` | إعادة تحميل `config/astra_physics.json` |

## الإعدادات

يُنشأ `config/astra_physics.json` عند أول تشغيل ويُعاد تحميله بـ `/astra reload`. كل قيمة تُفحص
حدودها عند التحميل، فتعديل الملف يدوياً ما يقدر يعطّل السيرفر. يغطي حدود البلوكات والمركبات،
الجاذبية، التخميد، الطفو، حدود السرعة الأربعة، مسافة الرسم، إضاءة العالم، إخفاء البلوكات الداخلية،
ميزانية الجسيمات، الحماية، وحدود معدّل الحزم.

## الحفظ

المركبات تُحفظ مع العالم، ملف لكل بُعد تحت `data/astra_physics/`، بكتابة ذرّية وحفظ تلقائي كل عشر
دقائق وعند الإغلاق. البلوكات تُخزَّن باسمها في الـ registry مو برقمها، فإضافة أو حذف مود ما يقدر
يغيّر تفسير سفينة محفوظة بصمت — وإذا راح مود بلوك معيّن، السجل يذكر بالضبط أي بلوكات سقطت.

## البناء

```bash
gradle clean build --no-daemon      # أو ./BUILD-TERMUX.sh على أندرويد
```

في `tools/` مولّدان وأداة فحص:

```bash
python3 tools/generate_models.py    # موديلات المكوّنات وملفات blockstate
python3 tools/generate_data.py      # ملفات اللغة، جداول الإسقاط، الوصفات، الوسوم
python3 tools/validate.py           # فحوص لا يقدر عليها مترجم جافا
```

`validate.py` يمسك ما لا يمسكه بناء ناجح: رسالة بلا ترجمة، blockstate يشير لموديل تغيّر اسمه،
موديل يذكر تكستشر غير موجود، هندسة خارج المدى الذي يحمّله ماينكرافت، وبلوك متحرك عدد إطاراته لا
يطابق موديلاته. شغّله قبل كل بناء؛ و`BUILD-TERMUX.sh` يسوي ذلك أصلاً.

تعديل الأشكال يكون في `tools/generate_models.py` وإعادة تشغيله، مو بتعديل الـ JSON المولَّد يدوياً.
`tools/model_kit.py` يتكفّل بالجزء الصعب: ماينكرافت ما يخبز إلا دورانات 0 و ±22.5 و ±45 درجة حول
محور واحد، فأي شيء بزاوية اعتباطية — مقود مُدار، دولاب توازن يدور — يُوضع عند أقرب ربع دورة والباقي
يصير دوران مخبوز.

## حدود معروفة

هذي فجوات معلنة، مو أخطاء:

- **الدوران حول المحور العمودي فقط.** المركبات تستدير يميناً ويساراً، لكنها لا تميل للأمام أو
  للجانب. التلامس مع التضاريس عند الزوايا الوسطى يحصل مبكراً قليلاً، لأن البلوك المُدار يُفحص
  بالصندوق الذي يحيط به.
- **كيانات البلوك تحتفظ ببياناتها لكنها لا تعمل.** الصناديق والبراميل والأفران والقمعيات تشتغل
  كتخزين على المتن، والقمعيات المحلية تنقل الأغراض بينها. الأفران ما تصهر والآلات المعدّلة ما
  تشتغل حتى يوجد ShipLevel حقيقي.
- **التفكيك يرجّع محتويات الصناديق، مو كل بيانات كيان البلوك.** الصندوق يرجع ممتلئاً؛ لكن إعدادات
  آلة معدّلة ما ترجع معه.
- **المركبات ليست تصادماً أصلياً.** دعم اللاعب ودفعه يُعالجان صراحةً، لذا الوحوش والمقذوفات
  والكيانات الأخرى لا تصطدم بالمركبة.
